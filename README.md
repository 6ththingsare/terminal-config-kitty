# terminal-config-kitty

Good terminal config for Kitty.  
Хороший конфиг терминала для Kitty.

---

## EN

### Fastfetch & Fastfetch Photos
* **Fastfetch:** Simply run `nano ~/.config/fastfetch/config.jsonc`
* **Fastfetch photos:** Create a folder (with any name you like) and place your photos inside it, then configure the path in `bashrc`.

### Bashrc
* In the `bashrc` file, go to **line 25**, delete the comment `#: path to the folder containing photos (my fastfetch photos)`, and insert the path to the folder where your fastfetch photos are stored.

### Kitty Config
* Simply run `nano ~/.config/kitty/kitty.conf`

## RU

### Fastfetch и фото для Fastfetch
* **Fastfetch:** Просто выполните `nano ~/.config/fastfetch/config.jsonc`
* **Фото для Fastfetch:** Создайте папку (с любым названием, какое вам нравится) и поместите туда свои фото, затем укажите путь в `bashrc`.

### Bashrc
* В файле `bashrc` перейдите на **25-ю строку**, удалите комментарий `#: path to the folder containing photos (my fastfetch photos)` и вставьте путь к папке, где хранятся ваши фото для fastfetch.

### Конфиг Kitty
* Просто выполните `nano ~/.config/kitty/kitty.conf`
